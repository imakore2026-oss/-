# PDF自動リスト化ツール（株式会社マルガメ様）

「注文・加工依頼書」「作業指示書」の2つのPDFに入力・保存すると、
自動的に内容がExcel（`受注・作業リスト.xlsx`）へ一覧化される仕組みです。

## フォルダ構成

```
forms/                          … 元になる入力用PDFのテンプレート（コピーして使う）
  order_form_template.pdf         … 注文・加工依頼書
  work_instruction_template.pdf   … 作業指示書
tool/
  watch_folder.py               … 監視・自動反映プログラム本体
  start.bat                     … これをダブルクリックして起動（Windows用）
  field_map_order.json          … 「注文・加工依頼書」の項目名⇔Excel列名の対応表
  field_map_work.json           … 「作業指示書」の項目名⇔Excel列名の対応表
記入済みPDF/                     … ★入力済みPDFを保存する場所（初回起動時に自動作成）
受注・作業リスト.xlsx            … ★自動生成されるExcel一覧（初回起動時に自動作成）
```

※ ファイル名は、Windowsでの文字化けを避けるためすべて半角英数字にしています。
　 （日本語は画面表示やExcelの列名の中でのみ使われます）

## 使い方

### 1. 初回セットアップ（最初の1回だけ）

1. この一式のフォルダを、担当者のパソコンの分かりやすい場所（デスクトップなど）にコピーします。
2. `tool` フォルダの中の **「start.bat」** をダブルクリックします。
3. パソコンにPythonが入っていない場合は自動でインストールが始まります。
   完了後に「ウィンドウを閉じてもう一度ダブルクリックしてください」と表示されるので、
   指示通りにもう一度 **「start.bat」** をダブルクリックしてください。
   （インターネット接続が必要です）
4. 黒い画面（コマンドウィンドウ）が開き、監視が始まれば準備完了です。

### 2. 日々の使い方

1. `forms` フォルダの中のテンプレートPDFを開き、内容を入力します。
   （Adobe Acrobat Reader、Chrome、Foxitなど、フォーム入力に対応したPDF閲覧ソフトで入力できます）
2. 入力が終わったら、**「名前を付けて保存」** で `記入済みPDF` フォルダの中に保存します。
   ファイル名は自由です（例：`20260805_○○様_発注書.pdf`）。
3. 「start.bat」を起動したウィンドウを開いたままにしておくと、
   保存してから数秒以内に自動で `受注・作業リスト.xlsx` に内容が追加・更新されます。
4. 同じファイル名で保存し直す（内容を修正して上書き保存する）と、
   Excel側も新しい行を追加せず、同じ行の内容が上書き更新されます。
5. 終了するときは、黒い画面を選んで `Ctrl+C` を押すか、ウィンドウを閉じてください。

### 注意事項

- `受注・作業リスト.xlsx` を自分で開いている間（Excelで編集中など）は、
  自動保存ができません。その場合は「Excelファイルが開かれているため保存できません」と
  表示されますので、Excelを閉じれば自動的に再試行され、反映されます。
- 対応しているのは `forms` フォルダにある2種類のテンプレートから作成したPDFのみです。
  全く別のPDFを保存しても「対応していない様式です」と表示されるだけで、無視されます。
- 列の名前や対象項目を変更したい場合は、`tool/field_map_order.json` /
  `tool/field_map_work.json` をテキストエディタで開き、`"label"` の文字列を書き換えれば
  次回起動時から反映されます（`"name"` は変更しないでください）。
- パソコンの起動のたびに自動で監視を始めたい場合は、「start.bat」のショートカットを
  Windowsの「スタートアップ」フォルダ（`shell:startup` で開けます）に入れておくと、
  ログイン時に自動的に起動します。

## 仕組みについて（技術的な補足）

- 2つのPDFにはあらかじめ入力用の項目（フォームフィールド）が設定されています。
- `watch_folder.py` は `記入済みPDF` フォルダを数秒おきに確認し、更新されたPDFがあれば
  `pypdf` で入力値を読み取り、`openpyxl` で `受注・作業リスト.xlsx` に反映します。
- PDF自体がファイルへ書き込む権限を持たない（セキュリティ上の制約）ため、
  「PDF側のボタンで直接Excelを書き換える」方式ではなく、
  フォルダを監視する常駐プログラムと組み合わせる方式にしています。
